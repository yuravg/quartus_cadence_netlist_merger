# Quartus Cadence Netlist Merger

[![Python Version](https://img.shields.io/badge/python-2.7%20%7C%203.4+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A command-line tool with GUI for merging Quartus Prime Pin files with Cadence PCB Editor
(Allegro) Netlists.

## Overview

Quartus Cadence Netlist Merger (qp_cnl_merger Quartus Prime, Cadence Net List, Merger) is a
utility that merges information from Intel Quartus Prime Pin files with Cadence PCB Editor
(Allegro) Netlists. This tool may be required by Quartus Prime FPGA developers working with
Cadence Allegro design.

### What it does

The tool reads:
- **Quartus Prime Pin file** - Quartus Prime output file (*.pin), contains FPGA pin assignments
  with location, direction, I/O standard.
- **Cadence Allegro Netlist** (pstxnet.dat) - Netlist, generated by Cadence PCB Editor.

And produces a merged output that maps Cadence net names and pin names to Quartus pin information.

### Example

**Input: Quartus pin file**
```
Pin Name/Usage               : Location  : Dir.   : I/O Standard      : Voltage : I/O Bank  : User Assignment
-------------------------------------------------------------------------------------------------------------
GND+                         : AA11      :        :                   :         : 3         :
f333                         : AA12      : input  : LVDS              :         : 4         : Y
data1_rx[4]                  : AA13      : input  : LVDS              :         : 4         : Y
```

**Output: Merged file with Cadence net names**
```
Net Name (Capture):  Pin Name/Usage               : Location  : Dir.   : I/O Standard      : Voltage : I/O Bank  : User Assignment
-------------------------------------------------------------------------------------------------------------
GND                  GND+                         : AA11      :        :                   :         : 3         :
F333P                f333                         : AA12      : input  : LVDS              :         : 4         : Y
DATA1P4              data1_rx[4]                  : AA13      : input  : LVDS              :         : 4         : Y
```

## Features

- Merge Quartus pin files with Cadence Allegro netlists
- GUI interface for easy file selection and configuration
- Command-line interface for automation
- Automatic backup of output files (preserves up to 100 versions)
- Configurable reference designator (refdes) selection
- Pin name rename masks for custom transformations
- Summary reports with statistics
- Python 2.7 and Python 3.4+ compatible
- No external dependencies (uses only standard library)

## Requirements

- **Python**: 2.7 or 3.4+
- **Operating System**: Linux, Windows
- **GUI**: Tkinter (usually included with Python)
- **Dependencies**: None (standard library only)

## Installation

### Option 1: Install from Release

1. Download the latest `.whl` file from [Releases](https://github.com/yuravg/quartus_cadence_netlist_merger/releases)

2. Install using pip:
```bash
pip install quartus_cadence_netlist_merger-<version>.whl
```

### Option 2: Build and Install from Source

```bash
# Clone the repository:
git clone https://github.com/yuravg/quartus_cadence_netlist_merger.git
cd quartus_cadence_netlist_merger

# Build the wheel package:
make build

# Install the package:
make install
```

Or manually:
```bash
pip install dist/quartus_cadence_netlist_merger-<version>.whl
```

### Verify Installation

```bash
qp_cnl_merger --version
```

## Usage

### GUI Mode (Default)

Launch the graphical interface:

```bash
qp_cnl_merger
```

The GUI allows you to:
1. Select Quartus pin file (*.pin)
2. Select Cadence netlist file (pstxnet.dat)
3. Configure reference designator (refdes)
